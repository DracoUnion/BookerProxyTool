# BookerProxyTool 代码结构

ApacheCN 代理 IP 工具箱：扫描代理存活、从公开源抓取代理、本地代理转发、可用性/点击行为测试，默认以 SQLite 库（`proxy.db`，SQLAlchemy ORM）管理代理池。命令行入口：`BookerProxyTool`（见 pyproject.toml）。

代码全部位于 `BookerProxyTool/` 包内，按职责分为 4 类模块：

## 1. 入口与命令注册

+ `__main__.py` — 唯一入口。构建顶层 `argparse` 解析器（`-v/--version`），注册 `scan`、`crawl`、`forward`、`test`、`click` 五个子命令，最后 `args.func(args)` 派发。
+ `__init__.py` — 包元信息（`__version__` = 2026.10.13.0，SATA 协议，作者 wizardforcel）。

## 2. 子命令模块

+ `scan.py` — `scan`：代理存活扫描（并发探测可用性）。
+ `crawl.py` — `crawl`：从公开代理源抓取代理列表。
+ `forward.py` — `forward`：本地代理转发服务。
+ `test.py` — `test`：代理可用性与速度测试。
+ `click.py` — `click`：代理点击/行为测试。

各模块暴露 `reg_subparser(subparsers)` 与 CLI 入口函数，由 `__main__.py` 注册后 `args.func(args)` 派发。

## 3. 数据层

+ `db/` — 数据访问层：`model.py` 定义 SQLAlchemy ORM 模型（代理字段：IP、端口、协议、匿名度、响应时间、存活时间等），默认 SQLite 库 `proxy.db`；`db.py` 封装增删改查与会话管理。

## 4. 共享基础设施

+ `util.py` — 通用工具（网络请求、文件/路径、日志等）。

## 5. 项目子目录

+ `doc/` — 本项目结构说明文档。

关键约定与 BookerMarkdownTool 一致：子命令名 `sub-cmd` 对应模块 `sub_cmd.py`；在 `<sub_cmd>.py` 中写 `reg_subparser(subparsers)`，再到 `__main__.py` 中注册。
